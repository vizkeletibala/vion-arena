# Unity ProjectSettings

This directory is intentionally minimal because the scaffold was created on a headless EC2 host without the Unity Editor.

Andrew should open the repository root as a Unity project on Windows using Unity 2022.3 LTS. Unity will generate the remaining ProjectSettings files, Library cache, and `.meta` files for newly imported assets. Commit generated ProjectSettings changes that represent real project decisions; do not commit Library/ or other local caches.
